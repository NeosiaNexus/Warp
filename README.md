# Benchmark history

This branch holds the timing history of Warp's hot-path benchmarks, published with GitHub Pages at
https://neosianexus.github.io/Warp/benchmarks/.

The [Benchmarks workflow](https://github.com/NeosiaNexus/Warp/blob/main/.github/workflows/benchmarks.yml)
appends a point to `benchmarks/data.js` on every push to `main`. Do not edit this branch by hand: see
[Benchmarks](https://github.com/NeosiaNexus/Warp/blob/main/CONTRIBUTING.md#benchmarks) in CONTRIBUTING.md.
